不启动宿主会话，不写 `~/.claude` / `~/.codex`。日志 `catalog_identity.sha256` 为
`1ef8289d…d104`，与 `v0.2.0` 中 `config/routing.catalog.v2.json` 的 sha256 一致。

## 注意

- 本轮发版所在的 Claude 会话以 `TIER_GUARD_MODE=audit claude` 启动（shell 历史可查），该变量只存在于这个进程，
  shell 配置、`~/.claude/settings.json`、`~/.codex/config.toml`、`launchctl` 中均没有；此类会话仍按 audit 运行。
  新开的会话才会使用默认 guard。
- 公开的两份研究文档含 Claude 会话 UUID 与 Codex 线程 ID（非凭据），推送前已告知用户。
